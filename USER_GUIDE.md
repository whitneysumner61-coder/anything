## Getting Started

When you first open the Productivity Dashboard, you'll see three main tabs:
- **📝 Tasks** - Manage your to-do list
- **⏱️ Pomodoro** - Focus timer for work sessions
- **📓 Notes** - Quick note-taking

Click any tab to switch between features. All your data is saved automatically in your browser.

## Task Manager

### Creating Tasks

1. Enter a task title in the "Task title" field
2. Optionally add a description
3. Select a category:
   - **Work** - Job-related tasks
   - **Personal** - Personal errands and activities
   - **Urgent** - Time-sensitive tasks
   - **Other** - General tasks
4. Choose a priority level:
   - **High** - Important, urgent tasks
   - **Medium** - Standard tasks
   - **Low** - Nice-to-have tasks
5. Click "Add Task"

### Managing Tasks

**Complete a task:**
- Click the checkbox next to the task
- Completed tasks appear with a strikethrough
- Uncheck to mark as incomplete again

**Filter tasks:**
- **All** - Show all tasks
- **Active** - Show only incomplete tasks
- **Completed** - Show only completed tasks

**Delete a task:**
- Click the "Delete" button on the right side of any task

### Understanding Statistics

At the top of the Task Manager, you'll see:
- **Total** - All tasks (blue)
- **Active** - Incomplete tasks (yellow)
- **Completed** - Finished tasks (green)

### Visual Indicators

Tasks are color-coded:
- **Categories**: Blue (Work), Purple (Personal), Red (Urgent), Gray (Other)
- **Priority**: Red (High), Yellow (Medium), Green (Low)

## Pomodoro Timer

The Pomodoro Technique helps you focus by breaking work into intervals.

### How It Works

1. **Work Session** (default: 25 minutes)
   - Focus on a single task
   - Avoid distractions
   
2. **Short Break** (default: 5 minutes)
   - Rest and recharge
   - Stretch, get water
   
3. **Long Break** (default: 15 minutes after 4 sessions)
   - Take a longer rest
   - Step away from your desk

### Using the Timer

**Start a session:**
1. Click "Start" to begin the timer
2. Work until the timer completes
3. You'll see a notification when time's up

**Controls:**
- **Start/Pause** - Begin or pause the timer
- **Reset** - Reset to the beginning of current mode
- **Skip** - Skip to the next mode (work → break → work)

**Session Counter:**
- Tracks how many work sessions you've completed
- Resets when you close the browser

### Customizing Settings

1. Click "Show Settings"
2. Adjust durations:
   - Work Duration (1-60 minutes)
   - Short Break (1-30 minutes)
   - Long Break (1-60 minutes)
   - Sessions Until Long Break (1-10)
3. Click "Save Settings"

### Notifications

The timer can send browser notifications when sessions complete:
1. Your browser will ask for permission
2. Click "Allow" to enable notifications
3. You'll be notified even if the tab is in the background

## Notes

Quick and easy note-taking for ideas, reminders, and information.

### Creating Notes

1. Click "+ New Note"
2. A new note appears in edit mode
3. Type your title and content
4. Click "Save"

### Editing Notes

1. Click a note from the list to select it
2. Click "Edit" to enter edit mode
3. Make your changes
4. Click "Save" to keep changes
5. Click "Cancel" to discard changes

### Organizing Notes

- Notes are sorted by most recently updated
- Each note shows:
  - Title
  - Preview of content
  - Last updated timestamp

### Deleting Notes

1. Select the note
2. Click "Edit"
3. Click "Delete" (red button)

## Data Management

### Where Is My Data Stored?

All data is stored in your browser's localStorage:
- ✅ Private - never leaves your device
- ✅ No account needed
- ✅ Works offline
- ⚠️ Browser-specific (different browsers = different data)
- ⚠️ Clearing browser data will erase everything

### Backing Up Your Data

Currently, there's no built-in backup feature. To preserve your data:
1. Don't clear browser data/cache
2. Use the same browser consistently
3. Consider taking screenshots of important information

### Switching Browsers

Data doesn't sync between browsers. If you switch:
1. You'll start with empty data in the new browser
2. Data remains in the original browser
3. Both can be used independently

## Tips & Tricks

### Task Management
- Use categories to organize by context
- Set high priority for today's most important tasks
- Review and clean up completed tasks weekly
- Add detailed descriptions for complex tasks

### Pomodoro Technique
- Commit to the full 25 minutes without interruptions
- Use breaks to physically move around
- Track which tasks you complete during each session
- Adjust durations to match your natural focus rhythm
- Turn off notifications on your devices during work sessions

### Note-Taking
- Create a note for each project or topic
- Use descriptive titles for easy finding
- Update notes instead of creating duplicates
- Review notes regularly to keep them current
- Use notes as a scratch pad during Pomodoro sessions

### Productivity Workflow

**Example Morning Routine:**
1. Open Tasks tab
2. Add today's tasks with priorities
3. Review and organize
4. Switch to Pomodoro tab
5. Start first work session
6. Use Notes tab during breaks for quick thoughts

**Example Task Session:**
1. Pick one high-priority task
2. Start Pomodoro timer
3. Work only on that task
4. When timer completes, check off the task
5. Take your break
6. Repeat with next task

## Troubleshooting

### Data Not Saving
- Check if cookies/storage are enabled
- Don't use private/incognito mode
- Ensure browser isn't clearing data on exit

### Timer Not Working
- Check browser tab isn't sleeping
- Keep tab active during countdown
- Try refreshing the page

### Notifications Not Showing
- Check browser notification permissions
- Enable notifications in browser settings
- Some browsers block notifications by default

### Performance Issues
- Clear old completed tasks regularly
- Delete unused notes
- Try refreshing the page
- Close other browser tabs
